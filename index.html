life-mode

life-mode is a small personal tool written and used by one person — Panu Wiwattanapa — to organise their own day (a morning plan, an evening wrap-up, and a weekly review) and their own personal inbox.

What it does with Google data

With the owner's own permission, the tool works only with the owner's own Gmail account (pookenz@gmail.com):

  • Read-only daily summary (https://www.googleapis.com/auth/gmail.readonly): how many messages are unread and which important messages arrived (sender and subject line only).
  • Mailbox assistant (https://www.googleapis.com/auth/gmail.modify, optionally https://www.googleapis.com/auth/gmail.settings.basic): on the owner's instruction, read and organise mail (labels, archive, Trash), draft replies, send messages the owner has approved one by one, and create simple filters. It cannot permanently delete mail or set up forwarding.

Who can use it

Only the owner. It is not offered to the public, there are no other users, and there is nothing to sign up for.
