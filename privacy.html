Privacy Policy — life-mode

Last updated: 10 October 2026 (added mailbox organising and sending)

life-mode is a personal, single-user tool operated by Panu Wiwattanapa (the "owner") for the owner's own use. It is not a public service and has no other users.

Google user data the tool accesses

The tool works only with the owner's own Gmail account (pookenz@gmail.com), and only after the owner grants access. It uses two separate grants:

  1. Morning summary — read-only (gmail.readonly): the number of unread inbox messages from the last day, and the sender and subject line of up to five unread messages that Gmail marks as important.
  2. Mailbox assistant (gmail.modify, and optionally gmail.settings.basic): on the owner's instruction, the owner's personal assistant software can read messages (headers, text and attachment names), apply or remove labels, archive, mark as read, move messages to Trash (and restore them), create drafts, send drafts the owner has approved, and create simple Gmail filters that label, archive or mark mail as read.

Safeguards built into the tool:

  • It cannot permanently delete mail — it does not request the scope that allows that, so "delete" always means moving to Trash, which Gmail keeps for 30 days.
  • It cannot set up automatic forwarding to any address.
  • Every message it sends is shown to the owner first (recipients, subject, full text and attachments) and is sent only after the owner approves that exact version.
  • Actions on many messages at once are proposed as a plan and run only after the owner approves; every action is logged and can be undone.

How the data is used

The data is used only to help the owner read, organise and answer the owner's own email, and to build the owner's private daily summary. To do this, message headers and text may be passed to AI language-model services chosen by the owner (for example OpenAI or Google Gemini). Those services process the text under their own terms; the owner does not use this data to train or improve any AI model. Content inside emails is treated as information, never as instructions to the tool.

Storage and sharing

  • The OAuth refresh token is stored in a file readable only by the owner on the owner's own computer.
  • Message content is not copied into any database. The tool keeps a local log of its actions (message IDs and labels, not message content); a generated summary and copies of draft replies may be saved in the owner's private notes.
  • The data is not sold, not used for advertising, and not shared with any other person.

Retention and deletion

The owner can revoke access at any time at myaccount.google.com/permissions and delete the token file; the tool then has no access to the account.

Google API Services User Data Policy

The use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
