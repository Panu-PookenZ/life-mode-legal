Privacy Policy — life-mode

Last updated: 10 October 2026

life-mode is a personal, single-user tool operated by Panu Wiwattanapa (the "owner") for his own use. It is not a public service and has no other users.

Google user data the tool accesses

When the owner grants access, the tool uses the Gmail API with the read-only scope gmail.readonly on the owner's own account (pookenz@gmail.com). It reads:

  • the number of unread messages in the inbox from the last day, and
  • the sender and subject line of up to five unread messages that Gmail marks as important.

It does not read message bodies or attachments, and it cannot send, delete, label or change any message.

How the data is used

This information is used only to build the owner's own private morning summary. To write that summary, the sender and subject lines may be passed to an AI language-model service chosen by the owner (for example Google Gemini). Those services process the text under their own terms; the owner does not use this data to train or improve any AI model.

Storage and sharing

  • The OAuth refresh token is stored in a file readable only by the owner on the owner's own computer.
  • Message content is not copied into any database. A generated summary may be saved in the owner's private notes.
  • The data is not sold, not used for advertising, and not shared with any other person.

Retention and deletion

The owner can revoke access at any time at myaccount.google.com/permissions and delete the token file; the tool then has no access to the account.

Google API Services User Data Policy

The use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
